# Kindergarten math coverage

The IXL plan is used as a topic checklist; its score ranges are not predictions or scores for this app. These skills appear individually on the Math map and are available to Quest, check-up planning, placement planning and skip-ahead. Adaptive runs choose a subset of eligible skills rather than promising every topic in one sitting.

| Topic | Skill IDs |
| --- | --- |
| Count to 120 using sequences, number lines and charts | `m.sequence120`, `m.line120`, `m.chart120` |
| Number words and digits | `m.words-digits`, `m.digits-words` |
| Wide/narrow; holds more/less | `m.width`, `m.capacity` |
| Same/different; sort by color or shape | `m.same-different`, `m.sort-color`, `m.sort-shape` |
| Sort and count in Venn diagrams | `m.venn-sort`, `m.venn-count` |
| Locate items in a grid | `m.grid-location` |
| Picture and cube addition, subtraction and stories | `m.put-together`, `m.take-apart`, `m.picture-story` |

Separate mock-only pools and mock coverage are not implemented by this content change; they are required before claiming independent mock evidence. Capacity questions use full boxes of equal-size cubes, rather than relying on the apparent size of unrelated emoji containers. New concepts use their own skill IDs to preserve prior attempts.
