# Reading plan coverage

The Kindergarten and Grade 1 IXL plans are topic checklists, not a basis for predicting an i-Ready score. The six new map skills offer listening practice for short-vowel identification and r-controlled vowel sounds, common prefixes and suffixes, and simple inferences at two levels. Each has separate authored practice and held-out mock questions; question selection within a mock does not guarantee that every individual skill will appear.

These additions do not complete every task in the plans. In particular, comparing and sorting syllables, ordering individual phonemes, long-versus-short vowel sorting, decoding and spelling r-controlled words, broader morphology, and many separate literary and informational text tasks require further coverage. Existing broad skills cover parts of several of these areas, but should not be interpreted as complete coverage. The r-controlled skill assesses listening to sounds, not independent decoding. The word-part skills cover selected examples rather than all affixes.

Grade 1 skills are shown when the existing Show stretch skills setting is on. No saved state migration is needed for these new IDs.
